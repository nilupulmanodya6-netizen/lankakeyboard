
# GitHub එකෙන් APK හදන හැටි - Android Studio නැතුව

1. github.com එකේ New Repository හදන්න - නම: LankaKeyboard

2. මේ Folder එකේ තියෙන files ටික ඔක්කොම Upload කරන්න
   (Add file > Upload files > මේ Folder එකේ ඇතුලේ තියෙන ඔක්කොම drag කරන්න)

3. Commit කරන්න

4. උඩ තියෙන "Actions" Tab එකට යන්න
   - "Build Lanka Keyboard APK" කියලා Workflow එකක් Run වෙනවා පේනවා
   - විනාඩි 3-4ක් යනවා
   - Green Tick එකක් ආවම ඒක Click කරන්න
   - යට "Artifacts" කියන තැන "Lanka-Keyboard-Pro-APK" කියලා තියෙනවා - ඒක Download කරන්න

5. ඒ APK එක Phone එකට දාගෙන Install කරන්න!
